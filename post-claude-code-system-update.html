Claude Code Deletes Servers, Databases, and Backups During System Update

Category: Engineering / Infrastructure

Image Source: ChatGPT

Developer Alexey Grigorev was using Claude Code to assist in migrating parts of a cloud environment managed through Terraform on AWS. During the process, a key configuration file was missing, leaving the system with an incomplete picture of the existing infrastructure. Claude generated a plan that Terraform then executed to reconcile the environment, bringing the declared configuration into alignment with what it understood to be the current state of the system.

In doing so, the system treated significant portions of the live environment as unnecessary. As a result, it deleted core infrastructure components, including servers, databases, associated storage, and backups. Within a few minutes, the automated action removed approximately 2.5 years of operational data.

Implications/bottom line: The data was ultimately recovered, but the incident is cited as a reminder of the need for caution when using AI agents.
